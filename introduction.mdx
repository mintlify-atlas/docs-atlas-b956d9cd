Kiosco is a browser-based virtual store built for small kiosks and delivery businesses, particularly those operating in Peru. It runs entirely in the browser using `localStorage` as its database — no server, no installation, and no backend required. Open a single HTML file and you have a fully functional online store with a product catalog, shopping cart, order management system, admin dashboard, and electronic invoicing.

## Who it's for

Kiosco is designed for small business owners who need a working online store quickly — without paying for hosting, learning a backend framework, or managing a database. It is particularly suited to:

- **Kiosk owners** selling snacks, beverages, and everyday goods to walk-in and delivery customers
- **Delivery businesses in Peru** that accept Yape and Plin as primary payment methods and need scheduled delivery windows
- **Solo operators** who want to manage everything from a phone or tablet without a dedicated point-of-sale system

<Note>
  Kiosco uses Peruvian phone number formats (`+51...`) and Peruvian sol (`S/`) as currency by default. The invoicing system includes IGV (18% VAT) as required by SUNAT regulations.
</Note>

## How it works

Kiosco stores all data — products, orders, settings, invoices, activity logs — in the browser's `localStorage`. There is no network request to a backend. When a customer places an order, the data is written to `localStorage` on their device. The admin reads that same data when viewing the order list.

This design means:

- **Zero infrastructure cost.** Deploy to any static file host: GitHub Pages, Netlify, Vercel, or even a USB drive.
- **Works offline.** Once loaded, the app continues to function without an internet connection thanks to the service worker.
- **Data stays local.** Nothing leaves the browser. This makes Kiosco appropriate for operators who prefer not to rely on third-party cloud services.

<Tip>
  Because data lives in `localStorage`, it is scoped to the browser and device. If you want multiple devices to share the same order list, deploy Kiosco to a hosted URL and access it from each device — they will each maintain their own local data. See [Deployment](/reference/deployment) for hosting options.
</Tip>

## The three pages

Kiosco consists of three HTML pages, each serving a distinct role:

| Page | File | Who uses it |
|------|------|-------------|
| Customer store | `index.html` | Customers browse the catalog, add items to the cart, and place orders |
| Admin panel | `admin.html` | The store owner manages products, orders, settings, and analytics |
| Order tracking | `client-orders.html` | Customers look up their order history and real-time status by phone number |
